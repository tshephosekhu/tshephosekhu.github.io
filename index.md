## ⚙️ Download & Install

Now, let's download and install the application.

1. On the Releases page, find the latest version.
2. Look for a file named **semantic-memory.zip** or **semantic-memory.exe**. This is the application file you need.
3. Click the file link to start the download.
4. Once the download completes, locate the file on your computer (usually in your Downloads folder).
5. If you downloaded a **.zip** file, right-click it and select "Extract All." Choose a folder to extract the files.

## 📖 Usage Instructions

After launching the application, you will see the main dashboard.

1. **Create a New Memory:**
   - Click on "Create Memory."
   - Input the necessary data and click "Save."

2. **Access Current Memories:**
   - Select "View Memories" to see your saved entries.
   - Click any entry to view its details.

3. **Edit or Delete Memories:**
   - Select a memory from the list.
   - Use the "Edit" or "Delete" options as needed.

4. **Export Memories:**
   - Want to save your memories externally? Use the "Export" feature to save your data.
